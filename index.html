TypeScript, de por qué a cómo

JavaScript creció hasta mover aplicaciones enormes, y con ellas llegaron los errores que solo aparecen en producción. Este curso cuenta cómo TypeScript resolvió ese problema, cómo funciona su sistema de tipos y cómo ganó en el frontend y en el backend, con laboratorios donde escribes un tipo y el compilador responde.

Cómo usar este curso

Estado. El curso está en preparación. La tabla de contenido ya tiene los 12 capítulos con sus secciones y sus laboratorios, y está en revisión.

Para quién es. Para quien ya escribe JavaScript y quiere tipos, y para quien llega de Java o C# y quiere entender el tipado estructural. Ayuda conocer funciones, objetos y promesas de JavaScript.

Cómo está hecho. Cada capítulo empieza con un problema real, muestra cómo lo resuelve el sistema de tipos y tiene laboratorios donde cambias el código y ves lo que el compilador acepta o rechaza.
